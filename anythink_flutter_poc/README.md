# Anythink Flutter SDK Playground

A small Flutter proof of concept built around the SDK surface described in the Flutter Engineer role.

## What it demonstrates
- Typed `AnythinkClient` configuration
- Auth session flow
- Storage/file upload flow
- REST health and project calls
- Responsive Material 3 example application
- Widget test covering the main SDK sections

## Verification
- Dart analyzer: **No issues found**
- Flutter widget test: **All tests passed**
- Flutter: 3.47.5
- Dart: 3.13.4

The backend operations are intentionally sandboxed/mocked so the sample can focus on API design and developer experience without requiring private credentials.
